# CLAWP 待验证清单

## Phase 0.4: 验证基础功能 ✅ 待测试

### 操作步骤
1. **下载 APK**
   - 访问 https://github.com/mesunrise/clawphone/actions
   - 点击最新的 workflow run
   - 在 "Artifacts" 区域下载 `clawp-debug-apk`
   - 解压 zip，安装 APK 到 Android 手机（需 Android 11+）

2. **配置 LLM**
   - 打开 CLAWP，点击右上角"设置"
   - 填入：
     - **API Key**: 你的 GPUGeek API Key
     - **Base URL**: `https://api.gpugeek.com/v1`
     - **Model Name**: `Vendor2/Claude-4.5-Sonnet`
   - 点击"保存"

3. **启用无障碍服务**
   - 返回主页，点击"开启无障碍服务"
   - 在系统设置中找到 CLAWP，启用

4. **验证状态**
   - 主页应显示：
     - ✅ 无障碍服务已启动
     - ✅ LLM 已配置
   - 通知栏应显示前台服务运行中

### 预期结果
- 应用正常启动，无崩溃
- 无障碍服务成功启用
- 前台服务在后台运行

## Phase 1: 飞书视频消息处理 🚧 开发中

### 操作步骤（开发完成后）
1. **配置飞书**
   - 在设置页填入：
     - **Feishu App ID**: 你的飞书应用 App ID
     - **Feishu App Secret**: 你的飞书应用 App Secret
   - 保存

2. **测试视频接收**
   - 在飞书中向机器人发送 1-2 个视频文件
   - 观察手机通知/日志，确认视频下载成功
   - 检查 `/Movies/clawp/` 目录是否有视频文件

### 预期结果
- 飞书 WebSocket 连接成功
- 视频文件下载到本地
- 视频出现在系统媒体库（抖音可见）

## Phase 4: 抖音发布自动化 🔜 待开发

### 操作步骤（开发完成后）
1. **手动走通抖音发布流程**（用于 UI 研究）
   - 打开抖音极速版
   - 点击底部"+"发布按钮
   - 选择一个视频
   - 添加话题（点击 # → 输入关键词 → 选择）
   - 点击发布
   - **截图每个步骤的界面**，或提供日志

2. **端到端测试**
   - 在飞书发送：2-3 个视频 + 文本指令
   - 例如："把这些视频发到抖音 #美食 #日常"
   - 观察手机自动操作
   - 检查抖音是否成功发布

### 预期结果
- Agent 自动打开抖音
- 自动选择视频、添加话题
- 成功发布作品
- 飞书收到成功/失败汇报
